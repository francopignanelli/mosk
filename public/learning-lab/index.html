How to interpret this experiment

CS+ is the odor paired with a modeled punishment input. CS− is the comparison odor. Conditioning changes effective Kenyon-cell (KC) connections to MBONs. Presenting an odor during imaging also affects this model, so tests are not passive observations. Extinction presents the odors without punishment. Retention includes timed gaps that allow the published decay dynamics to operate.

The model uses fitted mean parameters and six DAN/MBON response variables. It does not simulate every anatomical cell, an entire fly brain, spatial recollection, conscious memories or autobiographical statements. This assay has no appetite, predator or motor mapping. All memory here belongs to this assay; a new life starts a fresh assay.

The JavaScript port is cross-checked numerically against a separate Python translation of the authors' equations. MATLAB was not executed here. Comparisons reproduce deterministic mean-model behavior, not the paper's confidence intervals or new biological findings.
